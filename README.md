# TypeScript Practice Assignment

This project is part of the assignment for the "Mission 1: Become TypeScript Engineer" track. It focuses on core TypeScript concepts used in modern application development, especially type safety, generics, union handling, tuples, object-oriented programming, and asynchronous logic.

## Project Overview

The assignment includes:

- a TypeScript practice file: [solution.ts](./solution.ts)
- a conceptual note on access modifiers: [access-modifier-in-oop.md](./access-modifier-in-oop.md)
- a conceptual note on type narrowing: [type-narrowing.md](./type-narrowing.md)

## Learning Objectives

By completing this assignment, the learner should be able to:

- use function parameters and default values in TypeScript
- work with union types and narrow them safely
- use readonly tuples and destructuring effectively
- build reusable code with generics
- model data using interfaces
- apply access modifiers such as public, private, and protected in classes
- write and handle asynchronous logic with Promise-based validation

## Included Exercises

The code in [solution.ts](./solution.ts) demonstrates the following concepts:

1. Default parameters and arithmetic functions
2. Type narrowing using `typeof`
3. Readonly tuple handling for coordinates
4. Generic array concatenation
5. Interface-based filtering logic
6. Object-oriented design with access modifiers
7. Promise-based async validation flow

## How to Run

To run the TypeScript file, first make sure TypeScript is installed in your environment, then compile and execute the file:

```bash
npx tsc solution.ts
node solution.js
```

If you are using a TypeScript runner tool or editor that supports TS execution directly, you can also run it from there.
